# Neon Bastion 2 — Android releases

Signed Android builds of **Neon Bastion 2** (the Unity remake). This repo holds release files only; the game's source is private.

- **Download the latest APK:** see [Releases](https://github.com/psteen-coder/neon-bastion-2-android/releases/latest).
- **Update feed:** the game checks `https://raw.githubusercontent.com/psteen-coder/neon-bastion-2-android/dist/latest.json` on launch and offers newer builds.

Package id `com.psteencoder.neonbastion2`. It installs alongside the original Neon Bastion and doesn't replace it.

## Install (sideload)
1. Open the APK link on your Android phone and download it.
2. When asked, allow your browser to install unknown apps.
3. Tap the downloaded file and confirm **Install**.
